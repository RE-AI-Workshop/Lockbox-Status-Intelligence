# Throughline labs

You will run three labs in order. Each is 45 to 60 minutes.

Pairing is optional. Work on your own machine if you can.

## Who needs what

- Lab 1 uses the live Throughline site, Cursor, and the RAW board. You do not need the GitHub repo yet.
- Lab 2 and Lab 3 use the repo on your laptop. Fixes stay local. Do not deploy.

## Labs

1. [Prerequisites](00-prerequisites.md): Cursor in Agent, Atlassian token, MCP smoke test (10 to 15 minutes).
2. [Lab 1: file one ticket](01-jira-lab.md): hunt on the live site, then file one RAW issue.
3. [Lab 2: implement the ticket](02-dev-lab.md): clone, run locally, fix only your ticket.
4. [Lab 3: write tests](03-qa-lab.md): add a Playwright spec for that same ticket.

If a setup step is not working after 2 minutes, use the bypass in that lab and keep going.
