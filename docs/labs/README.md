# Throughline labs

You will hunt bugs on a live demo app, file Jira tickets, fix them locally, and write tests. Three labs, about 45 to 60 minutes each. Do them in order.

You can pair up, but everyone should stay on their own laptop if they can.

## What you need when

| Lab | You use | You do not need yet |
| --- | --- | --- |
| Prerequisites | Throughline, Cursor, RAW board | The GitHub repo |
| Lab 1 | Live site + Cursor + Jira | The GitHub repo |
| Lab 2 | GitHub repo on your machine | A deploy |
| Lab 3 | Same repo + your Lab 1 ticket | A deploy |

Fixes stay local in Lab 2 and Lab 3. Do not push or redeploy the shared demo site.

## Start here

1. [Prerequisites](00-prerequisites.md) (10 to 15 minutes, or homework before the session)
2. [Lab 1: file one ticket](01-jira-lab.md)
3. [Lab 2: implement the ticket](02-dev-lab.md)
4. [Lab 3: write tests](03-qa-lab.md)

If setup takes more than 2 minutes, use the bypass in that lab and keep moving.
