# SentriLock workflow kit

Download **[SentriLock-Workflow-Kit.zip](SentriLock-Workflow-Kit.zip)**.

Unzip it and open the kit’s own `README.md`. That file is the install guide: copy the prompts and extension into a SentriLock repository, fill `.github/ai/PROJECT.md` for that project, then install the extension.

This archive is a framework to integrate. It is not wired into Throughline and does not replace the workshop labs.
